# Demand forecasting benchmark

* Region: `tunis` (business timezone `Africa/Tunis`)
* Snapshot: `max(event_id)=52102`, git `2f1f7ab`, 4316 observed hours, holdout 864 h
* Runs logged to MLflow experiment `demand_forecasting`

**Data volume: 4316 hours** — the window covers weeks of history, so weekly seasonality and the lag-168 features have something real to learn; the backfilled structure (drift, weekend/holiday spikes, weather dips, outages, per-zone heterogeneity) is documented in scripts/backfill_order_history.py, and re-runs land in the same experiment so the volume-scaling story stays comparable.
