How it works

Four moving parts, one system of record

Every order, driver move and price quote is an event in the platform's pipeline — which is why the dashboards, the forecasts and the copilot all agree with each other.

Take & track orders

One API for the full lifecycle — pending, assigned, in transit, delivered — with an auditable history per order and per-customer records.

Dispatch the nearest driver

Real road distances, vehicle filters and live availability heartbeats. Drivers free up automatically on delivery; stale ones are swept offline.

Price & promise

Distance-based fees with demand-surge tiers, and arrival promises served by a trained ETA model — with a transparent fallback so quoting never stops.

Learn & watch

Hourly demand forecasts per zone, drift-checked models, a live ops dashboard, and an AI copilot that answers questions and narrates incidents.

Every tier below is shipped and running — nothing here is a promise on a roadmap. Each card links to the working evidence.

Tier 1 — Core operations

For the operator who needs one dependable system instead of five tools.

  • Full order lifecycle API with auditable event history
  • Geographic nearest-driver dispatch with live availability
  • Dynamic pricing with surge tiers and itemized quotes
  • Event pipeline feeding a governed warehouse
  • Live operations dashboard

Tier 2 — Intelligence

For the operator who wants the platform to see the next hour coming.

  • Hourly demand forecasts, per zone, retrained on schedule
  • Model-backed ETAs with transparent heuristic fallback
  • Drift watch: models that flag their own aging
  • Prometheus + Grafana monitoring with alert rules
  • Per-tenant isolation (database-enforced, not promise-enforced)
