Platform

Everything a delivery operation runs on

One system of record for orders, drivers, pricing and analytics — every state change event-logged, every rule unit-tested, every endpoint documented.

📦

Order management

Create orders and track the full lifecycle — pending → assigned → in transit → delivered — with an immutable event history per order.

📍

Driver dispatch

Geolocation-aware nearest-driver matching with vehicle filters and live availability heartbeats. Drivers free up automatically on delivery.

💸

Dynamic pricing

Distance-based fees with demand-surge tiers and a minimum-fee floor. Every quote returns a full, auditable breakdown.

⏱️

ETA estimation

Prep + travel + buffer heuristics today, with a benchmarked ML model on the roadmap that has to beat the baseline to ship.

📊

Operational analytics

KPI summaries — status mix, revenue, average delivery time, fleet availability — plus a Prometheus metrics endpoint for alerting.

🛡️

Production discipline

Fully typed (mypy), 92% coverage enforced in CI, dependency CVE audits, Docker packaging, and a protected main branch with required checks.

Architecture

Built in layers, growing in phases

A modular monolith today — pure business rules behind stable service interfaces — with a data and ML roadmap that slots in without rewriting the domain. 

flowchart LR
  U[Client] --> API[FastAPI REST API]
  API --> ORD[Order service]
  API --> DRV[Driver matching]
  API --> PRC[Pricing engine]
  API --> ANA[Analytics + Prometheus]
  ORD --> PG[(PostgreSQL)]
  DRV --> PG
  PRC --> PG
  ORD --> EV[order_events log]
  EV --> P2[Phase 2 · event pipeline + dbt]
  P2 --> P3[Phase 3 · forecasting + ML ETA]
  P3 -. feeds .-> PRC
Phase 1

Core platform

Orders, dispatch, pricing, ETA, analytics — live, typed, tested.

Phase 2

Data engineering

Event pipeline, warehouse models with dbt, orchestration, quality checks.

Phase 3

AI / ML

Demand forecasting by zone, ML ETA, forecast-driven dynamic pricing.

Phase 4

Dashboard

Operational KPIs, demand vs supply, drill-downs for the ops team.
